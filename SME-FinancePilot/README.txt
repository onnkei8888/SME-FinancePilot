SME FinancePilot 3D HQ — DEMO / SAMPLE

1. Extract this folder.
2. Open a terminal in this folder.
3. Install dependencies:
   python -m pip install -r requirements.txt
4. Run:
   python -m streamlit run app.py

The 3D scene loads Three.js from a CDN, so an internet connection is needed.
All business figures are illustrative sample inputs. The prototype performs
transparent Python calculations; it does not connect to bank accounts or make
real transactions. Agent building clicks show descriptions; run the workflow
from the Streamlit page to calculate the sample financial analysis.
